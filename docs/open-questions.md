# Open questions

## Settled

- Per-muscle weekly targets: default (2×/week), fully editable per muscle in Settings. Decided
  in Module 5.
- How adherence and coverage combine: they don't, not really — shown separately, plus a plain
  average shown alongside as a headline convenience. Decided in Module 5.
- Whether to track body weight over time: yes — a dedicated `weight_logs` table, a dashboard
  card, and a "Weight" tab with a trend chart and day-based log form. No target/goal weight, no
  BMI. Decided and built as Module 8.
